## ✨ Features

- **Modern UI/UX**: Built with React, Tailwind CSS, and Radix UI components for a sleek, dark-themed responsive design.
- **Smooth Animations**: Powered by GSAP and ScrollTrigger for complex scroll animations and dynamic element reveals.
- **Interactive 3D Elements**: Uses custom particle fields and WebGL components via React Three Fiber.
- **Functional Contact Form**: Direct email integration via FormSubmit without needing a backend server or exposed APIs.
- **Dynamic Configuration**: Fully driven by a centralized `config.ts` to easily update content, projects, and experiences dynamically without editing complex JSX.

## 🛠️ Tech Stack

- **Frontend Framework**: React 19, Vite
- **Styling**: Tailwind CSS, PostCSS
- **Animations**: GSAP (GreenSock), React Three Fiber (Three.js)
- **UI Components**: Radix UI, Lucide React icons
- **Form Handling**: React Hook Form, Zod
- **Notifications**: Sonner (Toast notifications)

## 📦 Getting Started

### Prerequisites

- Node.js (v18 or higher recommended)
- npm or yarn

### Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/yatharthmishra/portfolio.git
   cd app
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Run the development server:**
   ```bash
   npm run dev
   ```
   The application will be available at `http://localhost:5173`.

### 🏗️ Building for Production

To create a production build, run:

```bash
npm run build
```

You can preview the production build locally with:

```bash
npm run preview
```

## 📧 Contact Setup

The contact form uses [FormSubmit](https://formsubmit.co/) to handle email forwarding seamlessly.

1. Submit a test message on the contact form using your local server (`http://localhost:5173`).
2. Check the email configured in `Contact.tsx` (`yatharth.mishra2002@gmail.com`).
3. Click **Activate** in the activation email sent by FormSubmit.
4. Future submissions will land in your inbox automatically!
